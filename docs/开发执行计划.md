规格以 EcomPilot 仓库的 `ecompilot_project_roadmap.md`（项目四 EcomOps，图 3-4 ~ 3-8、4.1、4.2、5.2）为准；本文件只规定怎么做。统筹（Claude）全权负责；分工沿用 EcomPilot：统筹写内核与契约，Codex 写外围模块，Cursor 只依据契约写验收测试（不读实现）。

## 0. 目标与深度分级

交付物：EcomOps 四条 LangGraph 工作流 + FastAPI 网关(:8000) + PostgreSQL 15(:5433) + Vue 3 管理页(:3000 可选，由 :8000 同源提供) 的**全流程薄切片**，并与已完成的 EcomPilot(:8085) 真实联调。

| 等级 | 模块 |
|---|---|
| A 深实现 | claim_audit：三轨并发审核、条件路由、`interrupt/resume`、AsyncPostgresSaver、主管审批（并发点击两次只生效一次）、Outbox、对账协程、AC-TX-04 完整验收（含进程重启） |
| B 可用 | kb_qa（分类、检索、低分入队）+ 待补录发布状态机与幂等 upsert（AC-KB-01）；listing_compliance_review（三层判定）；cs_training（五阶段、SSE、记忆摘要修复）；JWT+RBAC 租户隔离 |
| C 最小 | Vue 3 管理页（CDN 引入，无构建）、MinIO（镜像拉取失败，用同接口本地文件回退）、"LLM" 用确定性规则实现并带 `fallback_used` 标志 |

不在范围：真实 EcomNLU/EcomRAG（桩，契约按路线图）、真实 LLM、真实 Milvus/BGE-M3。

## 3. 通用约束
1. 金额整型分；身份只来自 JWT（`sub`、`tenant_id`、`role`）；角色：`supervisor`、`operator`、`cs_agent`、`system`（内部调用用 `X-Internal-Token`）。
2. 租户隔离：所有业务表带 `tenant_id`，查询必须带租户条件；跨租户一律 404。
3. 幂等：`claim_no` 唯一；`refund_idempotency_key = "REFUND_"+claim_no+"_V1"`；节点副作用以 `step_execution_id` 防重入；发布 `chunk_id = sha256(queue_id:version)`。
4. 测试库隔离：每个测试一个 `ecomops_test_<uuid8>` 库（含 LangGraph 检查点表），结束删除。
5. 错误码统一见 `contracts/errors.md`；完成声明必须附实际运行的命令与输出。

## 5. 质量闸门
派发：每任务一个工作项（无 acceptance）+ `submit_task(mode=edit_worktree)`；评审：越界 diff 拒收，worktree 内实跑测试，对照契约；合并：worktree 提交后在主工作区 `git merge hub/<id>`；冲突裁决：测试读错规格→退回 Cursor；实现违规→返工；规格歧义→按"更保守"裁决并记入决策记录。

## 6. 版本控制
本仓库为公开仓库。全程**本地提交**；推送到 GitHub 需用户明确同意（长期授权只覆盖 EcomPilot），W4 结束时统一询问。

## 7. 何时才打断用户
需用户本人操作（登录/授权/付费）、系统级软件安装无权限、规格出现无法自行裁决的根本矛盾、对外发布（推送）。其余自行决策并记录。
