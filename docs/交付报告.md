## 3. 未完成项与已知缺陷
- 无真实 LLM：三轨的"证据归因"、问答生成、对练回复均为确定性规则；`fallback_used` 路径通过故障注入验证。
- RAG 为桩：无 BGE-M3/Milvus/CrossEncoder；`top1_score` 来自关键词打分。HyDE/多路改写为规则实现；Web 搜索 MCP 未实现。
- MinIO 未实测；`ecomops-docs` 桶逻辑只在代码中。
- 管理页没有补材料提交入口（买家补材料走内部接口 `/internal/v1/claims/{no}/evidence`，仅测试覆盖；EcomPilot 侧无对应调用入口）。
- 对账最大重试次数后转 `CALLBACK_FAILED_MANUAL`，但管理页没有专门的"人工告警台"，只能在列表里按状态筛选。
- 提交接口与出箱回调在同一进程内异步执行；多实例部署未测（出箱用 `FOR UPDATE SKIP LOCKED` 租约，设计上支持，未实测）。
- 开发令牌端点仅在 `ECOMOPS_DEV_TOKENS=1` 时存在；生产必须关闭并替换 `JWT_SECRET`、`INTERNAL_TOKEN`。
